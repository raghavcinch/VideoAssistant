# Editing-Books → Studio Role Alignment

This repo includes purchased reference books under `Editing-Books/`.

To keep this repository clean, we do **not** copy book text into docs. Instead, we:
- keep a structure-only index (TOC/headings) in `docs/editing_books_structure.json`
- convert the ideas into original, task-focused SOPs inside `.github/skills/`

## Where to look

- Book structure index: `docs/editing_books_structure.json`
- Studio roles (custom agents): `.github/agents/`
- SOP skills: `.github/skills/`

## Suggested mapping

- Color correction reference → `va-color` + color-related SOPs
- Resolve operational reference → `va-resolve-td`, `va-finishing`, `va-export`
- Editing theory / pacing / sequencing reference → `va-producer`, `va-editor`

## Output rule

When using these references, agents must:
- produce **original** checklists and step-by-step procedures
- avoid verbatim excerpts or long quotes from the books
- cite the book only at a high level (chapter/topic), not by copying text
